# TomKi Claude Work Collector

기존 **Claude Windows 데스크톱 앱**에서 현재 표시된 업무 문단을 공동 기록함으로 보내는 시험용 수집기입니다. 별도 AI 모델 API를 호출하지 않습니다.

이 프로젝트는 서로 다른 AI 활용 방법과 업무 스킬·정보를 공유하고, 실제 업무 효율 개선을 확인하기 위한 TomKi 공동 기록 공간의 Windows 연결 도구입니다.

## AI에게 링크 하나로 설치 부탁하기

아래 문장을 Claude Code, Codex 등 **Windows PC에서 파일 다운로드와 프로그램 실행이 가능한 AI**에게 전달하세요. 일반 채팅만 가능한 AI는 직접 설치할 수 없습니다.

> https://github.com/sunghwanki92/tomki-claude-work-collector 를 읽고 이 Windows PC에 설치해 줘. AGENTS.md와 install.ps1을 먼저 확인하고, 최신 릴리스 체크섬을 검증해서 설치 프로그램을 실행해 줘. Google 로그인과 PC 연결 승인은 내가 할게. 관리자 권한이나 보안 기능 해제는 하지 말고, 실제 Claude 업무 대화가 공동 사이트에 들어오기 전에는 자동 수집 성공이라고 말하지 마.

## 사람이 할 일

1. AI가 띄운 설치 창에서 **Google로 연결하고 자동 설치**를 누릅니다.
2. 열린 브라우저에서 Google 로그인 후 **이 PC 연결**을 승인합니다.
3. 기존 Claude 앱에서 업무 대화를 열고, 약 1분 뒤 [공동 사이트](https://macmini.tail25505f.ts.net:8443/)에 기록이 들어왔는지 확인합니다.

기기 이름 입력, 키 복사, 수동 자동 시작 등록은 필요하지 않습니다. Google 로그인은 공동 사이트 접근용입니다. 회사 Claude 계정의 비밀번호·쿠키를 요구하지 않습니다.

## AI 없이 설치

[최신 릴리스](https://github.com/sunghwanki92/tomki-claude-work-collector/releases/latest)에서 `TomKiClaudeCollector.exe`를 다운로드해 실행하고 위 순서대로 연결하세요. 코드 서명되지 않은 자체 도구입니다. 회사 보안 정책이 실행을 차단한다면 사내 담당자에게 승인받아야 합니다.

## 설치 스크립트

Windows PowerShell 5.1 이상에서 저장소를 받은 뒤:

```powershell
.\install.ps1
```

스크립트는 같은 저장소의 최신 GitHub 릴리스에서 실행 파일과 SHA-256 목록을 받아 일치 여부를 확인하고 설치 창을 엽니다. `-VerifyOnly`는 다운로드/체크섬 검증만 하고 실행하지 않습니다. 실행 정책이나 Defender/SmartScreen을 변경하지 않습니다.

## 현재 범위와 제한

- Claude 앱의 **현재 표시된 본문**에서 업무 표현이 있는 문단을 PC 안에서 선별합니다.
- 사이드바 대화 제목, 입력 중인 초안, 내부 대화 DB, 인증 쿠키, 첨부파일은 수집하지 않습니다.
- 닫히거나 최소화된 앱, 보이지 않는 과거 대화, 화면 밖의 긴 대화는 수집하지 못합니다.
- 본문 영역을 찾지 못하면 전체 창 수집으로 대체하지 않고 전송하지 않습니다. 앱 버전에 따라 수집이 안 될 수 있습니다.
- 규칙 기반 업무 선별이므로 누락·잘못된 포함이 있을 수 있습니다. **전체 대화 자동 백업 도구가 아닙니다.**
- Windows 실행/DPAPI/필터 시험, 서버 HTTPS 저장·중복 방지 검증을 통과했습니다. 동료 PC에서 실제 Claude UI 수집은 아직 검증 전입니다.

## 보관과 중지

설치 위치: `%LOCALAPPDATA%\TomKiClaudeCollector`. 기기 키와 전송 대기 파일은 Windows DPAPI로 해당 사용자 계정에 묶어 암호화합니다. 기기 키는 발췌 업로드만 허용하며 공동 기록 조회 권한이 없습니다.

트레이에서 수집 일시 중지·종료·자동 시작 해제·상태 파일 확인이 가능합니다. 사이트의 Windows 연결 화면에서 기기 키를 폐기할 수도 있습니다. 수집기는 30초마다 확인하며 대화 내용이 안정된 뒤 전송합니다. 대기열은 최대100건이며 서버가 중복을 제거합니다.

Google 승인 없이 자동 설치·기기 등록을 완료했다고 주장하지 마세요. 수집기 개발·설치 자료만 공개하며 회사 기록·키·실제 대화는 이 저장소에 넣지 않습니다.
